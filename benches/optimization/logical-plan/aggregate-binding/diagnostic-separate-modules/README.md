# Rejected separate-module factorial design

The first design compiled each control into a separate module. Non-extremum negative controls showed large changes even when only comparator direction differed, so these measurements cannot identify the intended direction effect. They are retained for audit and are excluded from the final causal conclusions. The shared-kernel experiment in the parent directory supersedes them.

Source preparation and the measured main source are retained alongside all raw samples, compiler/binary identities and summaries. The historical runner records its original local binary path; do not use it as the portable reproduction entry point. Use the parent experiment for reproduction and current conclusions.
